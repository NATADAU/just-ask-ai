Шпаргалка «Можно просто спросить»

Как начать любую задачу с ИИ: не объяснять всё сразу, а дать ИИ расспросить вас.

Три шага
  1. Опишите задачу одной фразойКак сказали бы коллеге: «хочу каждый месяц видеть посещаемость по группам».
  2. ИИ задаёт вопросы по одномуК каждому — варианты ответа. Выбираете или пишете свой.
  3. Готовое задание — в новый чатИИ соберёт ответы в задание. С ним открываете новый чат и работаете.
Универсальный запрос

Скопируйте и замените текст в скобках

Я хочу [задача одной фразой]. Прежде чем что-то делать, возьми у меня интервью: задавай вопросы по одному, к каждому — 3–4 варианта ответа. Спрашивай о том, о чём я могла не подумать: откуда данные, кто будет пользоваться, что может пойти не так. Я не программист — объясняй простыми словами. Настоящих данных я не присылаю, только устройство таблиц и выдуманные примеры. Когда всё будет понятно — составь готовое задание одним документом, чтобы я открыла с ним новый чат.

!Никаких настоящих данных: только устройство таблиц и выдуманные примеры.

В Claude Code вопросы приходят с кнопками. В обычном чате — Claude, ChatGPT, GigaChat и других — текстом с вариантами «а / б / в». Работает везде.

Четыре частые задачи — нажмите, чтобы раскрыть

1

Решить, стоит ли автоматизировать

Польза, деньги, риски⌄

Подойдёт, если задача повторяется каждый месяц и хочется понять, стоит ли тратить силы на автоматизацию.

Я думаю, стоит ли автоматизировать задачу: [что делаем и как часто]. Возьми у меня интервью: задавай вопросы по одному, к каждому — 3–4 варианта ответа. Выясни, сколько времени уходит сейчас, во что обойдётся автоматизация, какие есть риски для данных и кто будет поддерживать решение. В конце честно скажи, стоит ли, и с чего начать.

Первый вопрос ИИ может быть таким

Сколько часов в месяц уходит на эту задачу сейчас?

  • а) меньше 2
  • б) 2–10
  • в) больше 10
  • г) не знаю — давай посчитаем
2

Отчёт по посещаемости из выгрузки

Мониторинг за месяц, отчёт по одной семье⌄

Подойдёт, если нужно регулярно сводить посещаемость по группам или готовить отчёт для одной семьи за период.

Я хочу получать отчёт по посещаемости из выгрузки: [за месяц по группам / по одной семье за период]. Возьми у меня интервью: задавай вопросы по одному, к каждому — 3–4 варианта ответа. Узнай, откуда берутся данные и как устроена таблица, кто будет читать отчёт и как часто он нужен. Настоящих данных я не присылаю — только названия столбцов и выдуманные строки.

Первый вопрос ИИ может быть таким

Откуда берутся данные?

  • а) выгрузка из CRM в Excel
  • б) таблицы педагогов
  • в) бумажные табели
  • г) ещё не знаю
3

Заявка, отчёт, проверка сайта

Тексты и взгляд со стороны⌄

Подойдёт, если нужно подготовить текст или посмотреть на него глазами комиссии, читателя, посетителя сайта.

Мне нужно [подготовить заявку на грант / отчёт фонду / проверить сайт]. Возьми у меня интервью: задавай вопросы по одному, к каждому — 3–4 варианта ответа. Узнай, для кого этот текст, какие есть требования, что уже готово и что вызывает сомнения. Потом посмотри на результат глазами того, кто будет его читать, и назови слабые места.

Первый вопрос ИИ может быть таким

Что готовим в первую очередь?

  • а) заявку на грант
  • б) отчёт фонду
  • в) проверку сайта глазами посетителя
4

Научить коллег

Спланировать первое занятие по ИИ⌄

Подойдёт, если хочется провести для команды первое занятие по ИИ и не перегрузить людей.

Я хочу провести для коллег первое занятие по ИИ. Возьми у меня интервью: задавай вопросы по одному, к каждому — 3–4 варианта ответа. Узнай, кто будет учиться, сколько есть времени, какие задачи у коллег и какие правила про данные нужно объяснить. Потом составь план занятия с упражнениями на выдуманных данных.

  • б) пробовали, но редко
  • в) пользуются, хотят глубже
